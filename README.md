# Omarchy Additions

Independent apps and shell plugins for [Omarchy](https://omarchy.org/). Choose
the addition you want and follow its install guide.

| Addition | Type | What it does |
| --- | --- | --- |
| [Image Viewer](apps/image-viewer/README.md) | Desktop app | Browse local and mounted folders, zoom, and rotate photos. |
| [USB Storage](plugins/usb-storage/README.md) | Bar plugin | See connected USB drives and safely eject them from the Omarchy bar. |

Each addition has its own `bin/install` and a guide with a screenshot,
requirements, uninstall instructions, and development checks. Standalone apps
live under `apps/` and shell plugins under `plugins/`.
